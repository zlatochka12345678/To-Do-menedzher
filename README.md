 IT.TEAM — Академический Менеджер Задач
IT.TEAM — это адаптивное веб-приложение (PWA) для контроля дедлайнов и организации учебного процесса академической группы. Проект разработан по методологии Mobile-First, имеет кастомный интерфейс в глубоких тёмных тонах и адаптивную систему индикации горящих сроков.

🔥 Ключевые возможности
Автоматическая сортировка: Все учебные задачи автоматически выстраиваются по степени срочности — самый близкий дедлайн всегда находится вверху списка, а выполненные задачи опускаются вниз.

Умная цветовая индикация дедлайнов:

🟡 Жёлтая подсветка карточки — до сдачи работы осталось менее 24 часов.

🔴 Красная подсветка карточки — время на сдачу истекло (задача просрочена).

Постоянный фоновый мониторинг: Приложение каждую минуту пересчитывает оставшийся срок задач без ручного обновления страницы.

Мгновенная фильтрация: Быстрое разделение задач на вкладки «Все задачи», «Текущие» и «Выполненные».

Экран деталей задачи: Просмотр полной информации о задаче (приоритет, дедлайн, статус, описание) с возможностью отметить выполненной или удалить.

Мини-календарь: Отдельный экран с сеткой месяца и списком задач на выбранный день.

Раздел «Группа»: Список участников академической группы со статусами и статистикой.

Локальная база данных: Данные сохраняются на сервере в формате JSON. Задачи, приоритеты и отметки выполнения не пропадут после перезапуска сервера или закрытия вкладки.

Бесшовная навигация: Переходы между разделами «Задачи», «Календарь» и «Группа» через нижний таб-бар.

🛠 Архитектура и стек технологий
Проект разделён на клиентский интерфейс и легковесный бэкенд-сервер:

Backend: Python 3.10+ (FastAPI, Uvicorn, Pydantic)

Frontend: Vanilla JS (ES6+), HTML5, CSS3 (Custom Properties / CSS-переменные)

Database: Локальное файловое хранилище (JSON)

Тестирование: Pytest, Playwright (UI-тесты)

🚀 Пошаговая инструкция по запуску (для Windows)
Шаг 1. Открытие проекта в Visual Studio Code
Откройте VS Code.

Перейдите в меню Файл -> Открыть папку... и выберите директорию с проектом.

Откройте встроенный терминал комбинацией **Ctrl + \``** (илиТерминал->Создать терминал`).

Шаг 2. Настройка виртуального окружения (venv)
В окне терминала поочерёдно выполните:

Создайте изолированную среду:

powershell
python -m venv venv
Разрешите выполнение скриптов в PowerShell:

powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
Активируйте виртуальное окружение:

powershell
.venv\Scripts\activate
В начале строки терминала должна появиться зелёная плашка (.venv).

Шаг 3. Установка библиотек и запуск
Установите зависимости одной командой:

powershell
pip install -r requirements.txt
Запустите веб-сервер:

powershell
python main.py
После того как в консоли появится строчка INFO: Uvicorn running on http://127.0.0.1:8000, зажмите Ctrl и кликните по ссылке мышкой. Приложение откроется в браузере.

🧪 Запуск автотестов
Убедитесь, что виртуальное окружение активировано, и выполните:

powershell
pip install pytest playwright
playwright install chromium
pytest -v
test_api.py — проверяет создание, сортировку, переключение статуса и удаление задач через REST API.

test_frontend.py — проверяет цветовую индикацию дедлайнов, счётчики, фильтры и защиту от XSS в браузере.

🔒 Безопасность и отказоустойчивость
Защита от XSS: Все текстовые поля (название задач, описания, предметы) проходят очистку через функцию escapeHTML перед выводом на экран, блокируя инъекции вредоносных скриптов.

Автономность базы данных: Бэкенд-сервер при первом старте самостоятельно проверяет наличие папок static, templates и файла tasks.json. Если они отсутствуют — создаёт их автоматически без аварийного завершения программы.

Изоляция тестов: Автотесты подменяют DATA_FILE на временный файл, поэтому реальные задачи в tasks.json не затираются.
