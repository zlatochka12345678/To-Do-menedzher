To-Do Менеджер для студентов (IT-TEAM)
Мобильное приложение — специализированный таск-менеджер для студентов вузов и ссузов, предназначенный для организации личных учебных задач и общих дел академической группы.

📋 Описание
Приложение представляет собой классический To-Do список, но с адаптацией под учебный процесс. Главная цель — помочь учащимся эффективно организовывать свой учебный процесс, вовремя сдавать лабораторные и курсовые работы, а также легко синхронизировать общие дела внутри академической группы.

В отличие от универсальных планировщиков, интерфейс и логика работы приложения полностью адаптированы под реалии студенческой жизни, где ключевую роль играют строгие сроки сдачи и разделение задач по степени важности.

✨ Функционал
Экран «Задачи» (Главный)
Список задач в формате To-Do с чекбоксами для отметки выполнения.

Автоматическая сортировка задач по срочности (самые срочные — наверху).

Цветовая индикация срочности:

🟢 Нейтральный фон — времени до дедлайна достаточно.

🟡 Жёлтая подсветка — до дедлайна осталось менее 24 часов.

🔴 Красная подсветка — срок выполнения прошёл, задача не выполнена.

Панель фильтрации: «Все задачи», «Текущие», «Выполненные».

Кнопка добавления новой задачи («+»).

Создание задачи
При нажатии на «+» открывается форма с полями:

Название задачи;

Описание;

Приоритет (Высокий, Средний, Низкий);

Дедлайн (дата и время).

После нажатия кнопки «Создать задачу» задача добавляется в список.

Экран «Календарь»
Отображение дедлайнов задач.

Сортировка по дате.

Отображение приоритетов задач.

Возможность отметить задачу выполненной прямо из календаря.

Экран «Группа»
Общие задачи группы.

Синхронизация статусов.

Распределение ролей (например, староста).

Список состава группы с онлайн-статусами.

Ядро приложения
Локальное хранение данных (в текущей реализации — в памяти через StateFlow; предусмотрена архитектура для перехода на JSON / SQLite).

Автосортировка задач.

Фильтрация задач.

Приложение работает без подключения к интернету и сохраняет данные после закрытия или перезагрузки устройства (при интеграции с локальной БД).

🚀 Установка и запуск
Требования
Android Studio Ladybug (2024.2.1) или новее.

JDK 17+.

Android SDK с API 24+ (minSdk 24).

AGP (Android Gradle Plugin) 8.5.0+.

Шаги
Клонируйте репозиторий:

bash
git clone https://github.com/your-username/ToDo_menedzher.git
Откройте проект в Android Studio.

Дождитесь завершения Gradle Sync.

Подключите эмулятор или физическое устройство.

Нажмите Run ▶ (или Shift + F10).

Сборка APK
bash
./gradlew assembleDebug
Готовый APK будет находиться в app/build/outputs/apk/debug/.

🔮 Планы по развитию
□ Интеграция Room (SQLite) для постоянного хранения задач.
□ Синхронизация с облаком (Firebase / собственный backend).
□ Push-уведомления о приближающихся дедлайнах.
□ Экран «Детали задачи» с возможностью редактирования и удаления.
□ Полноценный календарь с выбором даты и отображением задач на конкретный день.
